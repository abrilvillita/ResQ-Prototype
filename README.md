## About
ResQ+ explores how a mobile emergency platform could guide people during disasters. The prototype focuses on clarity, urgency, accessible actions and an app-like flow.

## Concepts demonstrated
- Multi-screen mobile application shell
- Step-by-step emergency guidance
- Voice-interaction concept
- Animated counters and status feedback
- High-contrast incident interface
- Mobile safe-area support
- Navigation designed for stressful situations

## Technology
HTML5 · CSS3 · Vanilla JavaScript · Responsive mobile UI · App-style transitions

## Status and safety
**Concept prototype only.** It is not connected to emergency services, does not provide verified emergency instructions and must not be used during a real incident.

## Run locally
```bash
git clone https://github.com/abrilvillita/ResQ-Prototype.git
cd ResQ-Prototype
```
Open `index.html`; mobile viewport mode gives the intended presentation.
